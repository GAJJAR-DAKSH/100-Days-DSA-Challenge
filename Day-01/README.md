## 🧠 Patterns Practiced

* **Single Traversal** — Process an array in one pass.
* **Two Pointers** — Use two indexes to process an array efficiently.
* **Hashing** — Use a HashSet/HashMap to reduce repeated searching.
* **Prefix/Suffix** — Store cumulative information for efficient calculations.
* **Brute Force → Optimization** — Find a correct solution first, then improve its complexity.

---

## ⏱️ Complexity Goals

| Problem / Pattern      | Target                    |
| ---------------------- | ------------------------- |
| Array Traversal        | `O(n)`                    |
| Find Maximum / Minimum | `O(n)` time, `O(1)` space |
| Second Largest         | `O(n)` time, `O(1)` space |
| Reverse Array          | `O(n)` time, `O(1)` space |
| Duplicate Detection    | `O(n)` average            |
| Maximum Subarray       | `O(n)`                    |
| Two Pointer            | Usually `O(n)`            |

---

## 💡 Key Takeaways

* Always check the input constraints before choosing an approach.
* Avoid sorting when a linear traversal is sufficient.
* Look for opportunities to solve problems in a single pass.
* Prefer in-place solutions when extra space is unnecessary.
* Compare brute-force and optimized approaches before finalizing the solution.
* Always analyze both time and space complexity.
